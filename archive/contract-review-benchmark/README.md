# Archived Contract Review Benchmark

## Purpose

This directory preserves historical benchmark cases, examples, schemas, and reports from the former contract-review skills.

The related contract-review skills are no longer active in this repository. These files are retained for provenance and historical comparison only; they are not current legal guidance and should not be loaded as an active skill.

## Contents

- `benchmark/`: historical test cases and output schema
- `examples/`: historical example input and output
- `reports/`: historical comparison and self-test reports

The dates, model configuration, and evaluation results in these files describe the historical runs at the time they were produced. Re-run or independently verify them before relying on any result.

# Food / 食品与消费安全

Skills in this category help agents screen **packaged foods and related consumer-safety questions** using labels, public regulation, and brand/manufacturer records—not laboratory instruments.  
本分类下的 Skill 帮助 Agent 基于**标签、公开监管资料与品牌/生产企业记录**筛查预包装食品及相关消费安全问题——**不是**实验室检测设备。

## Shared expectations / 共同约定

- Prefer official and scientific primary sources over social media or marketing copy.  
  优先官方与科学一手来源，而非社交媒体或营销文案。
- Separate **legality**, **realistic exposure risk**, and **long-term nutrition quality**.  
  区分**合法性**、**现实暴露风险**与**长期营养质量**。
- Never invent concentrations, ADI percentages, or lab results that are not disclosed.  
  不得虚构浓度、ADI 占比或标签未披露的检测结果。
- Packaging alone cannot rule out residues, heavy metals, microbes, adulteration, or illegal additives.  
  包装本身无法排除残留、重金属、微生物、掺假或非法添加。

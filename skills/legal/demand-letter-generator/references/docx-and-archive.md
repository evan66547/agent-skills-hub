# DOCX 格式、依据归档与案卷

> 由 [`SKILL.md`](../SKILL.md) 按需加载。

## 1. DOCX 工作流

- 使用宿主可用的 Word/DOCX 能力读写与（可选）渲染。
- 存在参考/模板 DOCX 时：
  1. 复制或打开该文件；
  2. 在既有段落/run 上替换文本，保留加粗、对齐、间距、字体；
  3. 保留电话段，除非用户明确要求修改。
- 终稿应尽量渲染为页面图检查页数与版式；**仅文本抽取不足以终验**。
- 若无法渲染（无 LibreOffice/`soffice` 等）：明确说明，并回退检查——能否解析打开、段落数、关键文本增删、标题/落款/电话的字体字号加粗对齐、`stat` 等。

### 参考模板下的常见版式（有参考则跟参考）

- 尽量保持参考段落结构
- 字体常为 `仿宋`
- 标题「催款函」居中加粗
- 称谓段债务人名称与冒号可加粗（若模板如此）
- 落款公司、日期、电话：跟模板对齐与加粗
- 页数优先匹配参考，勿为压成一页破坏版式
- 正文过长时先压缩法言法语，再动视觉格式
- 已存在终稿文件名时默认更新该文件，除非用户要另存版本

## 2. 依据文件夹归档

终稿核验后（用户未关闭归档时）：

1. 在终稿同级创建 `依据/`（若不存在）
2. 催款函终稿留在父目录
3. 将所有非催款函支撑文件移入 `依据/`
4. 按类型 + 债务人 + 标识重命名
5. **禁止删除**；**禁止覆盖**（重名则加 `-2`、`-3`…）

### 命名模式

| 类型 | 模式 |
| --- | --- |
| 合同 | `合同-债务人名称-合同号.ext` |
| 发票 | `发票-债务人名称-发票号码或日期.ext` |
| 截图 | `截图-债务人名称-内容说明.ext` |
| 付款 | `付款凭证-债务人名称-金额或日期.ext` |
| 其他 | `依据-债务人名称-内容说明.ext` |

分类线索：文件名含「合同」/`XSHT`/合同号 → 合同；含「发票」/`dzfp`/发票号 → 发票；服务期/订单页图 → 截图；转账/回单 → 付款凭证。

### 归档核验

- 父目录仅保留终稿 `催款函-债务人名称.docx`（及用户要求保留的其他文件）
- `依据/` 存在且非催款函证据均在其内
- 文件名可读且带类型前缀

## 3. 案卷文件夹重命名

归档后在可行时重命名整案目录：

- 模式：`YYYYMMDD我方公司缩写-债务人名称-催款函`
- 日期：当天或函件日期（若明显不同）
- 我方缩写：由债权人稳定简称，如「示例信息科技有限公司」→「示例科技」
- 债务人：全称
- 目标名已存在则加 `-2`、`-3`…，不覆盖
- 确认文件夹内含终稿与 `依据/`

## 4. 整案移动（公开版强制确认）

移动整案前必须向用户确认：

1. **是否**移动；
2. **精确**目标目录路径。

**不要**假设默认桌面路径或任何本机私有路径。未获确认则不移动，并在回复中说明。

确认后移动；若目标下重名，加 `-2`、`-3`…，不覆盖。

# Tech / 技术与工程

Skills that help agents **evaluate, design, and land technical work**—especially AI systems—using live evidence, cost/risk trade-offs, and executable guidance.  
本分类帮助 Agent 用**实时证据、成本/风险权衡与可执行指引**来**评估、设计与落地**技术工作（尤其是 AI 系统）。

## Shared expectations / 共同约定

- Prefer live docs and active repos over model memory for version- and SOTA-sensitive claims.  
  对版本与「当前是否可行」类判断，优先实时文档与仍在维护的仓库。  
- Separate **capability**, **cost to run**, and **cost to operate**.  
  区分**能力是否够**、**跑得起的成本**与**养得起的运维**。  
- Label uncertainty and offline mode; never invent APIs or benchmarks.  
  标注不确定性与离线模式；禁止虚构接口或基准数据。
